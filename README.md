# Purva Birthday Gift

A personalised birthday website for Purva.

## Run locally
```bash
npm install
npm run dev
```

## Notes
- The original background song is preserved as `public/assets/bg-music.mp3`.
- The Welcome page uses the two newly supplied side videos.
- The memories album contains 19 photos and one short video memory.
- The birthday calendar highlights 7 November 2026 (Chhoti Diwali).
